Optional images for the Learning & Guide pages
===============================================

Place image files here to illustrate the guides. The guides reference these paths;
if a file is missing, the image will not show (the rest of the page still works).

Suggested filenames (used in guide content):
- cpu-socket.jpg    : CPU socket on motherboard (lever, alignment mark)
- ram-slots.jpg     : RAM slots on motherboard (DIMM slots with clips)
- m2-slot.jpg       : M.2 slot on motherboard (NVMe SSD slot)
- io-shield.jpg     : I/O shield (metal plate for case rear)
- standoffs.jpg     : Motherboard standoffs (brass posts)
- front-panel.jpg   : Front panel header pins on motherboard
- psu-cables.jpg    : 24-pin and CPU 8-pin power cables
- thermal-paste.jpg : Pea-sized thermal paste on CPU
- pcie-slot.jpg     : PCIe x16 slot (long slot for GPU)
- cpu-cooler.jpg    : Air or AIO CPU cooler

You can use your own photos or royalty-free images. JPG or PNG, reasonable size (e.g. 800–1200px wide).

Some guides also use images from the /hardware/ folder (e.g. product photos of CPU, RAM, GPU)
which are already in the project.
